ElasMapeiam — arquivos do aplicativo

Este ZIP contém o código-fonte, o sistema de design, as fontes e os testes.
Não contém senhas, dependências instaladas nem uma cópia dos dados do Lovable Cloud.
O mapa atual utiliza lugares fictícios.

Para abrir em um ambiente de desenvolvimento com Bun instalado:
1. Extraia este ZIP.
2. Copie .env.example para .env.local.
3. Execute bun install.
4. Execute bun run dev e abra o endereço mostrado.

A chave pública CARTO está em .env.example. Configurações privadas não foram exportadas.
Este é o código-fonte, não um instalador para Android ou iPhone.
